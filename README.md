# Prompt Fragments (조각 프롬) Extension for SillyTavern

프롬프트 조각을 관리하고 토글하여 기존 프롬프트와 결합할 수 있는 SillyTavern 확장입니다.

## 📋 기능 (Features)

### ✨ 주요 기능 (v1.0)
- **위치 모드 선택**: "상대적인" 또는 "깊이에 따라" 중 선택
- **카테고리별 설정**: 위치 모드, 역할을 카테고리 단위로 관리
- **카테고리 접기/펼치기**: 설정은 펼쳤을 때만 표시
- **카테고리 전체 ON/OFF**: 원형 토글 버튼
- **순서 변경**: ↑↓ 버튼으로 조정

### 🎯 기본 기능
- **카테고리별 관리**: 프롬프트 조각을 카테고리로 그룹화
- **조각 토글**: 각 조각을 원형 버튼으로 ON/OFF
- **편집 기능**: 제목과 내용을 자유롭게 편집
