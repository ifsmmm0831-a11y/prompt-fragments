# Prompt Fragments (조각 프롬) Extension for SillyTavern

프롬프트 조각을 관리하고 토글하여 기존 프롬프트와 결합할 수 있는 SillyTavern 확장입니다.

## 📋 기능 (Features)

### ✨ 주요 기능 (v1.0)
- **위치 모드 선택**: "상대적인" 또는 "깊이에 따라" 중 선택
- **카테고리별 설정**: 위치 모드, 역할을 카테고리 단위로 관리
- **카테고리 접기/펼치기**: 설정은 펼쳤을 때만 표시
- **카테고리 전체 ON/OFF**: 원형 토글 버튼
- **순서 변경**: ↑↓ 버튼으로 조정
- **깔끔한 UI**: 모든 버튼 한 줄 배치

### 🎯 기본 기능
- **카테고리별 관리**: 프롬프트 조각을 카테고리로 그룹화
- **조각 토글**: 각 조각을 원형 버튼으로 ON/OFF
- **편집 기능**: 제목과 내용을 자유롭게 편집
- **실시간 적용**: 메시지 생성 시 활성화된 조각들이 자동으로 추가됨

## 🚀 설치 방법 (Installation)

### 방법 1: SillyTavern 내장 설치 도구 (권장)

1. SillyTavern 실행
2. **Extensions** (블록 아이콘) 클릭
3. **Download Extensions & Assets** 클릭
4. "Prompt Fragments" 검색 후 **Download**

### 방법 2: 수동 설치

1. 4개 파일(manifest.json, index.js, style.css, README.md) 다운로드
2. `prompt-fragments` 폴더 생성 후 파일 복사
3. 다음 경로에 배치:
   - `SillyTavern\data\<user-handle>\extensions\prompt-fragments`
   - 또는 `SillyTavern\public\scripts\extensions\third-party\prompt-fragments`
4. SillyTavern 재시작

## 📖 사용 방법 (Usage)

### 1. 확장 활성화

1. Extensions 패널 열기
2. "Prompt Fragments (조각 프롬)" 찾기
3. 체크박스 활성화

### 2. 카테고리 생성

**UI 구조:**
```
[●] ← 전체 활성화 토글

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

▼ [●] 카테고리 이름 [↑][↓][삭제]
   위치: [상대적인 ▼] [System ▼] | 역할: [System ▼]
   
   [+ 조각 추가]
   
   [●] 조각 제목 [↑][↓][편집][삭제]
```

**카테고리 설정:**
1. **"+ 카테고리 추가"** 클릭
2. 카테고리 이름 입력
3. 펼치기(▼) 클릭하면 설정 표시:
   - **위치 모드**: 상대적인 / 깊이에 따라
   - **역할**: System / User / Assistant

### 3. 위치 모드 이해하기

#### 📍 상대적인 (Relative)
- SillyTavern의 기본 프롬프트 위치 사용
- **System**: 시스템 프롬프트 영역
- **Main**: 메인 프롬프트 영역  
- **Jailbreak**: 탈옥 프롬프트 영역
- 카테고리 순서대로 추가됨

#### 🔢 깊이에 따라 (By Depth)
- 깊이 값으로 정밀한 순서 제어
- **깊이 0** = 최우선 (가장 먼저)
- **깊이 999** = 최후순위 (가장 나중)
- 같은 깊이면 카테고리 순서대로
- 모든 프롬프트는 System 영역에 추가됨

**언제 사용?**
- **상대적인**: 간단한 설정, System/Main/Jailbreak 구분 필요
- **깊이에 따라**: 복잡한 구성, 정밀한 순서 제어 필요

### 4. 조각 추가

1. **"+ 조각 추가"** 클릭
2. **원형 토글**: ON(초록)/OFF(회색)
3. **제목** 입력
4. **편집** 버튼으로 내용 작성
5. **↑↓** 버튼으로 순서 조정

### 5. 실전 예시

#### 예시 1: 상대적인 모드
```
[●] 전체 활성화

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

▼ [●] 기본 설정
   위치: [상대적인] [System] | 역할: [System]
   
   [●] 친절한 성격
       내용: "항상 친절하게 대화합니다"
   
   [●] 전문가 지식
       내용: "AI 전문가입니다"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

▼ [●] 대화 스타일  
   위치: [상대적인] [Main] | 역할: [Assistant]
   
   [●] 간결한 답변
       내용: "간결하게 답변하세요"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

→ 결과:
  System Prompt에 "친절한 성격" + "전문가 지식"
  Main Prompt에 "간결한 답변"
```

#### 예시 2: 깊이에 따라 모드
```
[●] 전체 활성화

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

▼ [●] 핵심 규칙
   위치: [깊이에 따라] [깊이: 0] | 역할: [System]
   
   [●] 절대 규칙
       내용: "절대 욕설 금지"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

▼ [●] 일반 설정
   위치: [깊이에 따라] [깊이: 10] | 역할: [System]
   
   [●] 기본 성격
       내용: "친절한 성격"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

▼ [●] 임시 모드
   위치: [깊이에 따라] [깊이: 20] | 역할: [System]
   
   [●] 디버그 모드
       내용: "상세히 설명"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

→ 결과 (깊이 순서대로):
  1. "절대 규칙" (depth: 0)
  2. "기본 성격" (depth: 10)
  3. "디버그 모드" (depth: 20)
```

## 🎨 고급 활용법

### 위치 모드 전략

**시나리오 1: 간단한 구성**
```
상대적인 모드 사용
- 시스템 설정 → System Prompt
- 대화 스타일 → Main Prompt
- 제약 사항 → Jailbreak Prompt
```

**시나리오 2: 복잡한 계층 구조**
```
깊이에 따라 모드 사용
- 절대 규칙 (depth: 0)
- 기본 페르소나 (depth: 5)
- 상황별 모드 (depth: 10)
- 실험적 기능 (depth: 99)
```

### 역할(Role) 활용

- **System**: AI 설정, 제약조건, 기본 규칙
- **User**: 대화 주제, 시나리오, 사용자 관점
- **Assistant**: 응답 스타일, 말투, AI 관점

### 카테고리 구성 예시

```
1. [기본 페르소나] depth:0, System
2. [작업 모드] depth:10, System
3. [대화 스타일] depth:5, Assistant
4. [현재 상황] depth:15, User
```

## ⚙️ 설정 저장

- 모든 설정 자동 저장
- 재시작 후에도 유지

## 💡 팁

- **위치 모드**: 상대적인(간단) vs 깊이에 따라(정밀)
- **접기 활용**: 완성된 설정은 접어두기
- **토글**: 원형 버튼으로 빠른 ON/OFF
- **깊이 값**: 10단위로 설정하면 나중에 중간 추가 가능
  - 예: 0, 10, 20 → 나중에 15 추가 가능

## 🔧 문제 해결

### Extension이 안 보임
- 폴더 위치 확인
- 4개 파일 모두 존재 확인
- 재시작

### 프롬프트가 안 추가됨
- Extension 활성화 확인
- 카테고리 토글 확인 (원형 버튼 초록색)
- 조각 토글 확인
- F12 콘솔 에러 확인

### 순서가 이상함
- 위치 모드 확인 (상대적인 vs 깊이에 따라)
- 깊이 값 확인 (낮을수록 우선)
- 카테고리/조각 순서 확인
